# Codex 的＋選單：規劃模式與目標｜互動教學

介紹 Codex 輸入框「＋」選單的每一項，重點說明「規劃模式」（/plan）與「目標」（/goal）：起源、原理、比較、示範與展望。

- 線上觀看：https://appjust.github.io/codex-plan-goal/
- 版本：中文配音＋中英字幕、中文配音＋中越字幕、English narration＋英中字幕
- 互動練習：「該開哪一個？」「哪一個目標寫得好？」
- 資料查核日：2026-10-10（來源：openai/codex 官方 GitHub 發布紀錄、learn.chatgpt.com 官方文件）

## 本機開啟
```
python -m http.server 8000
```
再用瀏覽器開啟 http://localhost:8000/
